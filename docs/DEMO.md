# AI Maintenance Engineer: guided demonstration

A fresh live repair was recorded inside an isolated sample repository. The default browsing experience uses saved evidence with paid calls disabled.

## A focused walkthrough

1. **Choose an issue.**
2. **run the agent.**
3. **inspect its diff.**
4. **compare independent checks.**

Pause on the evidence at each decision: isolated execution; fresh agent reasoning; independent patch verification.
